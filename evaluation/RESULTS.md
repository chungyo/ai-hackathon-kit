# 로컬 검증 기록

## 2026-11-03: 스킬 진입점 정리

- 16개 진입점을 6개로 통합하고 기존 지침·Next.js·FastAPI·UI·데이터·서술형 자료를 선택형 참고자료로 보존했다.
- 로컬에서 6개 스킬 형식 검사, Markdown 상대 링크와 스킬 심볼릭 링크 점검, 기존 Next.js 예제 테스트 12개를 실행했다. 아래 과거 검증의 16개는 당시 구조를 뜻한다.
- 독립 에이전트 압박 시나리오, 실제 시험 플랫폼, Git clone, 3시간 전후 비교는 실행하지 않았다. 형식 검사나 예제 테스트는 시간 절감이나 실제 시험 성공을 증명하지 않는다.

이 기록은 시험 플랫폼 검증이나 모든 스킬의 성능 평가가 아니다. 테스트 입력은 가상의 예시이며 실제 시험 문제·자료는 포함하지 않는다.

## 2026-11-02: Next.js 데이터 처리·저장 학습 예제

- Next.js App Router의 데이터 검증·적용·재계산·저장과 사용자 설명을 연결하는 참고자료와 가상 예제 `next-dataset`을 추가했다. 실제 과제의 CSV·권한·노선 계산·출력 스키마를 구현한 것이 아니다.
- 로컬 Node 22.23.1에서 `node --experimental-strip-types --test route.test.mjs`로 handler 직접 호출과 실제 SQLite 파일을 사용하는 6개 테스트가 통과했다. 데이터 적용·계산·별도 Node 프로세스의 DB 재조회, 무효 입력·중복 ID의 거부, 데이터셋 교체 후 이전 결과 미노출, SQLite 쓰기 실패 시 롤백, 잘못된 JSON·미적용 계산을 확인했다. Node에서 SQLite 실험적 경고가 발생했다.
- 저장소 밖 임시 프로젝트에 Next.js 16.4.3과 React·TypeScript를 설치하고 예제 파일을 App Router 경로에 연결했다. `.ts` import 허용 등 임시 TypeScript 설정을 사용해 `next build`와 타입 검사가 통과했다. 루프백 HTTP에서 빈 상태, A 적용·계산, 무효 B 거부와 A 유지, B 적용 후 재계산 대기, B 계산을 확인했다. 서버 종료·재시작 후 동일 DB의 B 결과를 HTTP로 재조회했다. 이 확인을 위한 패키지는 저장소의 의존성에 추가하지 않았다.
- 별도 read-only `codex exec`에서 백엔드·기능별 설명 스킬과 예제 코드, 위 관측을 요약한 가상 평가 기록을 읽혔다. 응답은 검증→트랜잭션 저장→계산→결과 조회 흐름, 방식의 한계, 과거 실행 기록과 이번에 직접 수행하지 않은 검증을 구분했다. 이는 한 번의 설명 점검이며 사용자 이해도나 다른 과제에서의 성능을 입증하지 않는다.
- 위 HTTP 점검은 로컬 임시 환경과 가상 데이터에 한정된다. 실제 브라우저 UI, 로그인·인가, CSV 파싱·7종 데이터, Docker, 동시 요청, 실제 시험 환경의 설치·버전·실행은 확인하지 않았다. 핸들러 테스트와 별도의 Next 서버 점검은 각각의 범위로 해석한다.
- OPSCALE 구조 검증에서는 기존 `next-calculation`과 새 `next-dataset`의 `.mjs` 테스트가 GitHub Import 미지원 파일로 지적됐다. Codex용 예제를 유지하므로 OPSCALE import 준비 완료로 보지 않는다.

## 2026-11-02: 기능별 동작·판단·검증 설명

- 기능 하나를 구현·확인한 직후 동작 원리, 실제 선택 이유, 검증 입력·명령·관측, 미검증을 사용자에게 설명하도록 `build-small`과 FE·BE·단계 연결 스킬을 보강했다. 사용자 이해를 확인한 것으로 추정하거나 답을 기다리며 작업을 자동 중단하지 않도록 했다.
- 가상 정수 범위 검증 기능을 격리된 임시 폴더에서 로컬 `codex exec` 0.166.0으로 두 차례 각각 새로 구현·테스트했다. 첫 응답은 테스트 3개 통과와 동작을 설명했지만 선택 이유가 명확하지 않았다. `build-small`의 설명 형식을 보강한 뒤 두 번째 응답은 기능·동작, 선택 이유, 실행 명령과 대표 입력 결과, 확인 범위를 구분했으며 단위 테스트 3개가 통과했다.
- 두 차례는 작은 함수 하나에 대한 관찰이며 실제 웹 화면·DB·시험 플랫폼이나 다양한 과제에서의 설명 품질을 증명하지 않는다. 사용자가 내용을 이해했는지도 검증하지 않았다.
- 기본 스킬 형식 검사와 Markdown·심볼릭 링크 검사를 수행했다. 별도의 OPSCALE 구조 검사에서 이번에 수정한 4개 스킬은 통과했으나 `backend-implementation`은 기존 `route.test.mjs`의 OPSCALE GitHub Import 미지원 때문에 실패했다. Codex용 키트의 기존 예제는 변경하지 않았고, OPSCALE import 가능 여부와 별도로 보고한다.
